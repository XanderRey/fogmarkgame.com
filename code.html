A friend shared their island

Use it in Fogmark

  1. Copy the code above (or the whole message).
  2. Open Fogmark and choose Enter a friend's code on the title screen.
  3. Tap Paste. A seed code charts the same puzzles so you can race; an Atlas code visits their island. Times come along with it.

To race on the island you're already playing, paste it in Journal → Times instead.
